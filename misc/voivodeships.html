|                                                                      |
|   O nieudanej próbie pobicia rekordu przejechania pociągiem przez    |
|   wszystkie województwa.                                             |
|                                                                      |
|   W sumie to nigdy nie pisałom bloga i nie za bardzo wiem co robię.  |
|   Może to kogoś zainteresuje...                                      |
|                                                                      |
|   Więc w dniach 19 i 20 sierpnia 2026 roku podjęłyśmy się, z moją    |
|   serdeczną przyjaciółką Łucją Potok, próby pobicia rekordu usta-    |
|   nowionego rok wcześniej przez użytkowniczkę twittera Zosia.        |
|   Jej wynik to 23 godziny i 32 minuty. Dzięki letniej korekcie       |
|   rozkładu jazdy pociągów i uruchomieniu wakacyjnego połączenia      |
|   Latarnik relacji Bydgoszcz Główna - Hel spółki Arriva RP  możli-   |
|   we było uzyskanie czasu przejazdu 23 godzin i 09 minut.            |
|                                                                      |
|   Przygotowanie trasy przejazdu zajęło mi kilka godzin. Jedno było   |
|   pewne, początek lub koniec podróży musiał mieć miejsce w Choszcz-  |
|   nie. Po licznych próbach udało się znaleźć satysfakcjonujące roz-  |
|   wiązanie gdzie kończyłyśmy we wsi Warlubie w województwie Kujaw-   |
|   sko-Pomorskim. Ostateczna trasa wyglądała następująco:             |
|                                                                      |
|   IC  82170/431 Uznam/Ursa    Choszczno-Dębica                       |
|   IC  23109     Smok Wawelski Dębica-Kraków Główny                   |
|   EIP 3508                    Kraków Główny-Warszawa Wschodnia       |
|   R2  19869                   Warszawa Wschodnia-Siedlce             |
|   R21 10775                   Siedlce-Siemiatycze                    |
|   TLK 1112      Bocian        Siemiatycze-Siedlce                    |
|   R2  10687                   Siedlce-Łuków                          |
|   IC  2112      Czechowicz    Łuków-Warszawa Wschodnia               |
|   EIP 3502                    Warszawa Wschodnia-Tczew               |
|   Os  50220     Latarnik      Tczew-Warlubie                         |
|                                                                      |
|   Udało nam się ustalić termin na drugą połowę sierpnia. Choszczno   |
|   nie wydawało się ciekawą destynacją turystyczną więc zapadła de-   |
|   cyzja o spędzeniu dnia w Szczecinie. Dla mnie dniem wyjazdu był    |
|   18 sierpnia. Byłom wtedy w miejscowości Srbská Kamenice w kraju    |
|   usteckim na wakacjach z rodzicami. Pobudka o 02:30 aby dojechać    |
|   do Děčína na 03:57, kiedy to z dworca głównego miał odjechać       |
|   RailJet 479 Berliner. Aplikacja Můj vlak niestety nie poinformo-   |
|   wała mnie, że pociąg jest opóźniony kilkadziesiąt minut. Dopiero   |
|   z wyświetlaczy na dworcu dowiedziałom się o sytuacji. Najbliższym  |
|   Połączeniem do Pragi był Ryhlik 671 o 4:25, który do stacji Praha  |
|   hlavní nádraží przyjeżdzał o 6:10, dwie minuty po dojeździe moje-  |
|   go Comeniusa do Krakowa. Oczywiście Comenius odjechał planowo nie  |
|   było szans na przesiadkę. W Pradze poszłom do punktu obsługi Čes-  |
|   kich dráh, do okienka odpowiedzialnego za bilety międzynarodowe.   |
|   Po wytłumaczeniu sytuacji Pani stwierdziła że muszę udać się do    |
|   okienka odpowiedzialnego za informacje. Po odczekaniu na swoją ko- |
|   lej i ponownym wytłumaczeniu sytuacji Pani odesłała mnie ponownie  |
|   do biletów międzynarodowych. Postanowiłom nie czekać po raz trze-  |
|   ci w kolejce, tylko poczekać na podstawienie Baltic Expressa.      |
|   Konduktor wydawał mi się bardziej odpowiednią osobą do rozwiąza-   |
|   nia mojego problemu. W istocie tak było, zgodził się na podróż do  |
|   Międzylesia na bilecie z Comeniusa. W Międzylesiu następowała      |
|   zmiana załogi na polską i obowiązywał mój Multiprzejazd. Wyjazd    |
|   z Pragi nastąpił planowo, jednak w kraju pardubickim przez godzi-  |
|   nę staliśmy w tak zwanym polu z powodu prac torowych. Gdy ruszy-   |
|   liśmy w wagonie dały się syłyszeć ciche brawa, jednak opóźnienia   |
|   nie zmniejszyliśmy aż do Wrocławia, gdzie porzegnałom Baltica.     |
|   (Baltic jeszcze niespodziewanie wróci w tej historii, ale nie      |
|   uprzedzajmy faktów.) Przesiadłom się do IC 8312 Szkunera, również  |
|   opóźnionego. Zjadłom pierogi w Warsie i dojechałom do Krakowa      |
|   Głównego planowo o 15:33.                                          |
|                                                                      |
|                                                                      |
|   Szybka integracja z krako(w)skimi osobami razemowymi i zupełnie    |
|   przypadkowo również z osobami młodolewicowymi. Potem pićko w GK,   |
|   zakupy i czekanie na nasz pierwszy pociąg, jakim był TLK 38194     |
|   Wolin, którym jechałyśmy do Szczecina Głównego. Podróż w wagonie   |
|   sypialnym przebiegła bez problemów i ponad dziewięciu godzinach    |
|   jazdy obudziłyśmy się w województwie zachodniopomorskim, gdzie     |
|   za kilknaście godzin miało zacząć się nasze wyzwanie.
